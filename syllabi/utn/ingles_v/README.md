## Convenciones para agregar material

1. **Siempre** actualiza este `README.md` al agregar/remover archivos.
2. Los nombres de archivo van en **minúsculas con guiones bajos** (`material/guia_entrevista.pdf`).
3. Prefiere formatos abiertos: `.md` > `.pdf`. Evita `.docx`.
4. El material no debe violar derechos de autor; prefiere documentos oficiales de acceso público.
