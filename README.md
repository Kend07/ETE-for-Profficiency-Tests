# 📚 University Study Apps & Interactive Quizzes

Este repositorio contiene **aplicaciones web interactivas y quizzes de repaso** diseñados específicamente a partir de los planes de estudio de cursos universitarios 

El objetivo de este proyecto es brindar herramientas visuales, dinámicas y de autocorrección para que cualquier estudiante pueda repasar temas clave, vocabulario, estructuras gramaticales e intenciones comunicativas antes de sus evaluaciones orales y escritas.

---
# 🔓 Licencia y Open Source
Este proyecto es 100% Open Source y de libre acceso para la comunidad académica. Puedes usarlo, compartirlo, modificarlo y adaptarlo a las necesidades de tu universidad o curso sin ningún costo.


## 🌐 ¿Cómo utilizar las aplicaciones? 

Todas las herramientas web están construidas en **HTML, CSS (Tailwind) y JavaScript puro** sin frameworks ni terceros. lo que permite que se ejecuten directamente en cualquier navegador.


### 🛠️ Uso Local (sin internet)
Si prefieres usarlas en tu computadora de forma local:
1. Clona este repositorio o descarga la carpeta en formato `.ZIP`.
2. Abre cualquier archivo `.html` (por ejemplo, `utn_ingles_v_quiz.html`) directamente en tu navegador.
