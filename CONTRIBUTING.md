# ¿Como Colaborar?
Las contribuciones de estudiantes y docentes son bienvenidas. Si quieres agregar el quiz de un nuevo curso o mejorar un código existente:

- Haz un Fork de este repositorio.

- Crea una rama para tu aporte (git checkout -b feat/nuevo-curso-materia).

- Agrega tu archivo HTML / recurso interactivo.

- Realiza un Commit con tus cambios (git commit -m 'Añade Quiz interactivo para Curso X').

- Haz un Push a la rama (git push origin feat/nuevo-curso-materia).

- Abre un Pull Request para revisión.
